# Master's Thesis: Cerebellum-inspired deep learning models for predicting governing equations in dynamical systems

This repository provides a robust framework for learning Koopman operators of dynamical systems. It implements Extended Dynamic Mode Decomposition (EDMD), Neural Network-backed EDMD (NN-EDMD), and various baseline models (SINDy, MLP) with a highly stable, multi-tiered scaling pipeline designed to handle high-degree polynomial and delay embeddings without numerical explosions.
